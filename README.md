# 🎯 FocusGuard AI - Telemetri Ruang Kerja Visual & Pola Fokus

**FocusGuard AI** adalah aplikasi web computer vision inovatif yang dirancang untuk membantu pekerja berpengetahuan, siswa, dan peneliti mengukur serta meningkatkan kebiasaan belajar dan kerja mereka dengan memantau pola aktivitas fisik yang dapat diamati secara real-time.

## 🌟 Fitur Utama
1. **Pemantauan Fokus Waktu Nyata**:
   - Memantau orientasi kepala, postur tubuh, dan interaksi dengan perangkat fisik (misalnya ponsel cerdas).
2. **Skor Pola Fokus Objektif**:
   - Menghasilkan nilai empiris berdasarkan aktivitas dan kehadiran di ruang kerja.
3. **Peringatan & Deteksi Gangguan Otomatis**:
   - Mendeteksi penggunaan ponsel cerdas atau ketidakhadiran dalam jangka waktu tertentu dan mencatatnya ke dalam timeline.
4. **Kalibrasi Ruang Kerja Adaptif**:
   - Penyesuaian baseline awal selama 5 detik untuk mengakomodasi berbagai sudut kamera dan posisi duduk.
5. **Privasi & Keamanan Data (Zero-Cloud)**:
   - Data diproses sepenuhnya secara lokal di browser klien menggunakan webcam; data video tidak pernah diunggah ke server cloud.

---

## 🚀 Cara Menjalankan
1. Buka folder `focusguard-ai`.
2. Buka berkas `index.html` langsung di browser favorit Anda (Google Chrome, Edge, Firefox, Safari).
3. Pastikan Anda mengizinkan akses kamera saat diminta oleh browser agar deteksi visual dapat berjalan.
4. Tidak membutuhkan instalasi server maupun koneksi internet luar.
